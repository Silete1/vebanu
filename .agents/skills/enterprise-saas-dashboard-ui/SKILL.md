# Enterprise SaaS Dashboard UI

Use this skill for operational surfaces that need to feel dense, clear, and controllable.

## Structure

- Start with a narrow top summary and a clear filter bar.
- Group content into cards, tables, and status regions.
- Keep the most important actions near the data they affect.
- Favor scanability over decoration.

## Visual language

- White or light surfaces
- Thin borders
- Clear badges and status chips
- Compact charts and metrics
- Controlled spacing, not airy marketing spacing

## Avoid

- Generic hero-page formatting
- Oversized empty whitespace
- Decorative copy blocks
- Data presented without obvious action or meaning

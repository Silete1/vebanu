# ERP Odoo Website UI

Use this skill for the ANU website's business-facing presentation.

## Keep the site message tight

- Lead with process redesign and operational control.
- Present Odoo as the implementation platform, not the brand.
- Use language about visibility, approvals, workflow, reporting, and maturity.

## Build around these page types

- Home
- Services
- Industries
- Methodology
- Odoo ERP
- Articles
- Contact

## Visual rules

- White dominant background
- Blue accents only
- Structured cards and dashboards
- Process diagrams over generic agency visuals
- RTL-ready layout decisions from the start

## Avoid

- Fake client proof
- Generic software-agency copy
- Claims without evidence
- Decorative motion that does not explain the method

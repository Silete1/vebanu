# Frontend Design Review

Review the screen against the brief and the product's actual job.

## Check

- Hierarchy and reading order
- Spacing, alignment, and density
- Typography scale and line length
- Color contrast and state clarity
- Responsive behavior at desktop, tablet, and mobile
- Motion, if any, for restraint and purpose
- Accessibility basics: headings, labels, focus, and tap targets

## Output

- Call out concrete issues only.
- Prioritize blocking problems first.
- Tie each finding to a file, component, or section.
- Suggest the smallest fix that improves clarity.

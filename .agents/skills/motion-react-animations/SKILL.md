# Motion React Animations

Use this skill for small, intentional motion in React interfaces.

## Prefer

- Transform and opacity animations
- Short fades, slides, and staggered reveals
- Hover feedback that lifts or highlights slightly
- Layout transitions that explain state changes

## Rules

- Keep motion subordinate to content.
- Respect `prefers-reduced-motion`.
- Avoid scroll-jacking, heavy parallax, and decorative loops.
- Use the smallest animation that explains the change.

## Deliver

- Stable component code
- Clean entrance and exit states
- Minimal dependency footprint
- Animation values that stay calm on mobile

# Playwright Visual QA

Use this skill to inspect a UI in the browser and catch visual regressions.

## Check

- Desktop, tablet, and mobile layouts
- Hover, focus, open, and empty states
- Sticky headers, overlays, and menus
- Console errors and broken assets
- Screenshot diffs or before-and-after comparisons

## Capture

- Only the minimum screenshots needed for judgment.
- Name screenshots by page and breakpoint.
- Re-run after any fix that could shift layout.

## Report

- State what changed visually.
- Note any breakpoints that still need work.
- Separate cosmetic issues from functional failures.

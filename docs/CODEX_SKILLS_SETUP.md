## Skill Usage Map

For UI, layout, navigation, cards, grids, responsiveness, accessibility, and visual taste, use:

- `frontend-design`
- `web-design-guidelines`
- `design-taste-frontend`
- `high-end-visual-design`
- `redesign-existing-projects`

For Next.js, React, performance, composition, and maintainability, use:

- `vercel-react-best-practices`
- `next-best-practices`
- `vercel-composition-patterns`

For shadcn/ui work, use:

- `shadcn`

For animation, transition quality, interaction feel, motion design, and visual polish, use:

- `emil-design-eng`

For GSAP animation, scroll-driven animation, pinned sections, timelines, React cleanup, and performance-safe motion, use:

- `gsap-core`
- `gsap-timeline`
- `gsap-scrolltrigger`
- `gsap-react`
- `gsap-performance`

Use `emil-design-eng` for:

- hero animation
- animated architecture stack
- process-line animations
- card hover motion
- section reveal transitions
- navbar active-state transition
- CTA hover states
- dashboard mockup motion
- Magic UI component selection
- Motion/Framer Motion usage
- reducing animations that feel cheap, excessive, or distracting

Use the GSAP skills when work requires:

- pinned scrollytelling sections
- scrubbed timelines
- scroll-driven phase changes
- responsive `matchMedia()` animation setup
- `prefers-reduced-motion` fallbacks for advanced motion
- React-safe animation setup and cleanup with `useGSAP()`
- transform-only animation and ScrollTrigger performance review

For comparing multiple interface or interaction directions before choosing one, use:

- `design-an-interface`

Use `design-an-interface` for:

- navbar design options
- hero layout options
- animation system direction
- dashboard mockup layout
- bento grid structure
- article card design
- service/industry section structure
- mobile interaction patterns

For the Method section specifically, use:

- `gsap-scrolltrigger`
- `gsap-react`
- `gsap-performance`
- `emil-design-eng`
- `design-an-interface`

For testing, browser inspection, screenshots, and verification, use:

- `webapp-testing`
- `verification-before-completion`
- `systematic-debugging`

For SEO, page copy, article structure, metadata, and search visibility, use:

- `seo-audit`
